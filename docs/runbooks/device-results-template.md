# APP-01 기기 결과 입력 양식

**빈 양식 — WAITING_DEVICE / NOT_RUN.** 시험한 항목만 `PASS` 또는 `FAIL`로 바꾸고, 못 해본 항목은 `NOT_RUN`으로 둔다. 사용자 본명·기기 일련번호·개인 노트는 필요 없다. [시험 절차](device-baseline.md)를 참고한다.

자체 APK를 설치하지 못했다면 오류 문구와 설치 경로까지만 기록한다. 기존 공식 앱 시험을 자체 APK `PASS`로 옮기지 않는다. 개발자는 제공된 APK 증거를 대조하고 미실행 항목을 유지한 채 APP-01 판정·후속 결함을 작성한다. 이 양식 자체는 실행 증거가 아니다.
